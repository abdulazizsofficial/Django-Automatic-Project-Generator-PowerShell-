# Django Automatic Project Generator (PowerShell)

This is a PowerShell automation script that quickly creates a complete Django project setup in one run.

It removes all manual steps and generates:

## 🚀 Features

- Automatically creates virtual environment (`env`)
- Installs latest Django
- Creates Django project (user input)
- Creates Django app (user input)
- Automatically adds app to `INSTALLED_APPS`
- Runs migrations
- Runs migrate
- Creates admin superuser automatically
- Handles invalid names (spaces → underscore)
- Prevents script from closing instantly

---

## 📥 Requirements

Make sure you have:

- Python 3 installed
- PowerShell (Windows)
- pip working
- Internet connection
